# Data Dictionary

## processed/coastal_affordability_county_v0.csv

Planned fields:

| Field | Description |
|---|---|
| state | Two-letter state abbreviation |
| county_fips | Five-digit county FIPS code |
| county_name | County name |
| year | Calendar year |
| median_household_income | ACS median household income |
| typical_home_value | Annualized Zillow ZHVI typical home value |
| home_value_to_income_ratio | typical_home_value divided by median_household_income |
| income_source | Source label for income data |
| home_value_source | Source label for home value data |
| home_value_year_method | Method used to convert monthly home value data to annual value |
| notes | Optional notes |
